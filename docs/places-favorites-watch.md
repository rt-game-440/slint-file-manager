# 磁盘、收藏与目录变化同步（Issue #7）

## 侧栏
- 分组：收藏、此电脑（本地固定盘与可移动盘，含 USB 总线类型识别）、云盘（OneDrive／iCloud 的本地同步目录，存在才显示）、回收站（静态入口，归 Issue #8）。
- 点击侧栏与在地址栏输入路径走同一条浏览流程（`Controller::navigate`），历史、选择、不可用状态一致。
- 手机、相机（MTP）等非磁盘设备和未确认的网络位置不出现；无“此电脑”虚拟页。
- 盘符变化靠约 1 秒的 `GetLogicalDrives` 位掩码轮询发现（未使用 `WM_DEVICECHANGE`），变化时重新枚举；浏览中的位置所在盘消失时标签标为“位置不可用”，盘回来后自动恢复或按 F5/重试。

## 收藏
- 存储：`%LOCALAPPDATA%\slint-file-manager\favorites.json`（`--data-dir`／`SFM_DATA_DIR` 可改）；带 `version`；损坏时备份为 `favorites.backup-…-corrupt.json` 并以空收藏启动。
- 每项记录路径、显示名与所在卷序列号。状态：有效、`OtherVolume`（盘符被另一个卷占用）、`Offline`（卷不在线）、`Missing`（目录不存在）。非有效项灰显并带警告标记，点击只提示原因，绝不悄悄指向另一个磁盘上的同名路径。
- 添加／移除：工具栏星标或 Ctrl+D 切换当前目录；侧栏项的 × 移除。重启后保留。

## 目录变化同步
- `browse::watch::DirWatcher`：`Notify` 模式用 `ReadDirectoryChangesW`（共享全部访问，不阻止删除目录）；`Poll` 模式每 1.5 秒看目录修改时间，用于可弹出磁盘，避免持有句柄使“安全删除硬件”报告占用。Poll 只能发现新建、删除、重命名，看不到已有文件的内容修改，此时按 F5。
- 通知附带监视器编号，换目录后旧监视器的迟到通知被忽略；爆发的通知用 100ms 节拍去抖合并为一次读取，读取进行中再有通知则读完后补一次。
- 静默重载：后台读取后按名称与旧列表合并，选择与光标保留；内容完全一致时不重绘；与应用自身的刷新不会产生重复条目。
- 隐藏标签只标记 `needs_refresh`，切回时才读取。
- 目录消失或磁盘断开：标签进入“位置不可用”；监视线程退出后由探测定时重试，恢复后自动重新加载。
- F5 为可靠的手动刷新入口。

## 边界
- OneDrive／iCloud 只当作普通本地目录处理；云占位文件的“不隐式下载”由 Issue #14 负责。
- 网络驱动器（映射盘符）按其盘类型原样列出，未确认的网络位置不做发现。
- 真实 USB 的人工验收见 `docs/checklist/checklist.md` 的 Issue #7 小节；自动化用 `subst` 虚拟盘模拟插拔。
