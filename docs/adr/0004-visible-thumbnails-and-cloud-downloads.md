# 优先首屏缩略图，浏览不主动下载云端原文件

缩略图浏览是用户的核心使用方式，因此优先处理当前首屏的缩略图，同时保持滚动、选择和打开文件可用。损坏或处理缓慢的单个文件独立显示加载状态或图标，不等待全部缩略图齐备后才显示或开放整屏操作。

用户选择以避免隐式下载原文件为边界：对 OneDrive、iCloud 中尚未下载到本机的文件，默认只使用本地或云盘已提供的缩略图；若必须下载原文件才能生成缩略图，则显示占位图标。打开文件或用户明确要求下载时，才允许为该操作获取原文件。该决策约束本应用的浏览行为，不表示能够禁止同步客户端自身的下载活动。

此选择接受部分云端占位文件暂时没有缩略图，以避免单纯浏览目录就获取大量原文件。具体缩略图来源与云盘兼容性仍需验证。

生成过的缩略图使用本地持久缓存，关闭应用或重启电脑后仍可复用。用户接受以本地存储占用换取重复浏览时更少的生成工作；缓存必须有容量上限和清空入口，具体默认上限仍待确定。

## 原型验证目标

以用户提供的 60 张 WebP 图片目录作为首个案例：当前文件总量约 11.93 MiB，每张约 1,000 万至 1,200 万像素，位于 NVMe SSD。这里只记录匿名汇总，不记录用户的私人目录路径。

在应用已经运行、进入目录的场景下，以 200 毫秒内可操作、首次生成时正常文件的首屏缩略图 1 秒内齐全、重复访问时首屏缩略图 300 毫秒内齐全为目标。测试须固定窗口大小和首屏数量，并记录缓存条件；这不是已经达到的性能结论，也不能由目录统计推断原生文件管理器的卡顿根因。
