# 按常用软件清单验收文件选择对话框替代

文件选择对话框替代属于产品目标。用户接受先按常用软件建立兼容清单：清单内对应的打开或保存流程应显示本应用的选择器，并向发起操作的软件正确返回结果；暂不兼容的软件允许继续使用自己的对话框，随后逐步扩大覆盖。

选择这一范围，而不是将任何软件的所有对话框均可替换作为完成条件。具体软件、版本和支持的选择流程尚未确定；本决策不代表已经验证兼容性，也不预先确定接管技术。

按用户确认的交付顺序，先交付可独立日常使用的文件管理器，再接管系统打开入口，最后实现文件选择对话框替代。第三阶段开始前确定常用软件清单；这一能力仍属于总体目标，不作为首阶段可用版本的前置条件。
