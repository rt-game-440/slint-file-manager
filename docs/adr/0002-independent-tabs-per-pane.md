# 每个浏览面板拥有独立的标签组

为支持用户在来源目录和目标目录之间操作文件，采用左右浏览面板各自拥有标签组的组织方式，并支持切换到单栏。切换一侧的浏览标签不改变另一侧的当前标签；不采用每个标签包含一组左右目录的组织方式。

默认保留并恢复两侧的浏览会话，包括标签、当前位置、排序和视图方式。切成单栏时保留另一侧的状态；下次启动时恢复。外接磁盘未连接等导致位置不可用时，保留对应标签并提示位置不可用，不丢弃该标签。

外部请求打开目录时，优先激活已打开该路径的标签；不存在对应标签时，在现有窗口的当前面板新开标签。请求包含定位文件时，应定位并选中目标。该规则确定收到请求后的窗口行为，不代表系统入口接管已经实现或验证。
