## Issue #3 系统菜单与云文件兼容原型（2026-11-07）

结论文档：[docs/research/0003-shell-menu-and-cloud-compat.md](../research/0003-shell-menu-and-cloud-compat.md)

- [ ] **真人键盘／鼠标操作原生右键菜单**
  - 操作：在 `prototypes/shell-cloud-probe` 下执行 `cargo build --jobs 6`。准备夹具目录 `%TEMP%\slint-fm-probe-fixture`（含 a.txt），然后在终端运行 `target\debug\shell-cloud-probe.exe menu --items "%TEMP%\slint-fm-probe-fixture\a.txt" --mode track-cancel --manual`（`--manual` 表示程序不投递模拟按键）。菜单弹出后，用鼠标悬停或键盘方向键进入 NanaZip 子菜单，再按 Esc 逐层关闭，或点击菜单外部关闭。再把参数换成 `--mode track-select --manual`，手动点击“添加到 "a.7z"”。
  - 预期：菜单出现在鼠标位置，NanaZip 子菜单内容完整；用 Esc 或点击外部关闭后，程序输出“返回 0：菜单已取消”，进程正常退出；菜单没有残留在屏幕上。选择模式下会生成 a.7z。
  - 用户反馈：

- [ ] **Windows 11 上重跑菜单与云盘原型**（有 Win11 环境后）
  - 操作：按结论文档第 6 节的复现命令，在 Win11 上运行 `menu` 的 list / invoke / track-select / track-cancel，以及装有 OneDrive 或 iCloud 时的 `cloud-info` / `cloud-scan` / `thumb-scan --mode incache`。
  - 预期：记录 Win11 版本号；确认 NanaZip 子菜单能出现并执行，INCACHEONLY 的水合计数为 0。结果写回结论文档的“未覆盖”一节。

## Issue #4 A2 风格的基础文件浏览（2026-11-08）

自动化已覆盖：浏览逻辑单元测试、harness 交互脚本（导航、地址输入、选择、视图与排序、打开、过期结果）、26 张 100%／150% 截图基线、加载提示逐帧曲线。以下项目只能在真实窗口里由人判断。

- [ ] **无边框窗口的拖动、缩放、最大化与关闭**
  - 操作：运行 `target\release\slint-file-manager.exe`。按住侧栏顶部“文件管理器”标题区或工具栏空白处拖动窗口；双击这两处；拖动窗口四边和四角；依次点击右上角最小化、最大化／还原、关闭。
  - 预期：拖动跟手；双击在最大化与还原之间切换，按钮提示随之变为“还原”；四边四角都能改变大小，最小 640×420；最小化后可从任务栏恢复；关闭后进程退出。
  - 用户反馈：

- [ ] **真实默认应用打开（含中文长文件名）**
  - 操作：用 `--open=` 打开一个含中文长文件名的目录（例如先运行一次 `powershell -File scripts/harness.ps1 run` 生成 `%TEMP%\sfm-harness\样例目录`，再把其中的图片换成真实图片，或打开你自己的图片目录）。双击一张图片；选中一个 .txt 按 Enter；Ctrl 多选 3 个文件后按 Enter。
  - 预期：分别用系统默认应用打开且文件正确；多选时打开所选的全部文件（最多 16 个）；没有默认应用的类型在状态栏给出“有 N 个文件未能打开：…”的提示，程序不卡住。
  - 用户反馈：

- [ ] **键盘与鼠标的手感**
  - 操作：在约 60 张图片的目录中：方向键、Home／End、PageUp／PageDown 移动；Shift+方向键扩选；Ctrl+Space 切换；Ctrl+A；Enter 进入文件夹；Alt+←／→／↑、Backspace 导航；F4、Ctrl+L 或 Alt+D 进入地址编辑，输入路径回车，Esc 取消；切换网格与列表、在排序菜单和表头切换排序。
  - 预期：光标项始终可见（自动滚动），蓝色描边表示键盘光标，选中为浅蓝底；内容区失去焦点时选中变灰；切换视图和排序后选择不丢；地址编辑时快捷键不误触导航；进入 60 张图片的目录没有可感知的停顿。
  - 用户反馈：

- [ ] **系统文字大小与显示缩放**
  - 操作：Windows 设置 > 辅助功能 > 文字大小 调到 150%，重新启动程序；另在 显示 > 缩放 设为 150% 再看一次。
  - 预期：文字随设置放大，工具栏、侧栏、行高同步变大，没有文字被裁切到不可读；长文件名在网格中两行后省略、在列表中单行省略；路径过长时左侧以“…”收起。与 `tests/baselines/text-scale-150_*` 截图的布局一致。
  - 用户反馈：

- [ ] **与 A2 的整体观感对照**
  - 操作：打开 `artifacts/review/a2-vs-*.png`（左 A2、右实现）以及真实窗口，对照侧栏、融合顶栏、内容区、选中样式。
  - 预期：浅灰侧栏、融合顶栏、近白内容区、少量蓝色强调、细线图标、浅蓝圆角选中；未实现的操作（双栏、搜索、收藏等侧栏入口）显示为灰色不可用。缩略图、双栏、多标签、文件操作不在本单范围。
  - 用户反馈：

## Issue #6 双栏独立标签与会话恢复（2026-11-08）

自动化已覆盖：浏览工作区与会话的单元测试、harness 的双栏交互脚本与重启恢复脚本（快捷键、标签归属、单栏往返、位置不可用、会话降级）、新增 5 个双栏场景的 100%／150% 基线、真实程序的会话闭环脚本 `scripts/verify-session.ps1`。以下项目需要真人键盘与真实环境确认。

- [ ] **键盘全流程：标签与面板切换**
  - 操作：运行 `target\release\slint-file-manager.exe`（默认双栏）。先按 F6 在两个面板间切换；在左面板按 Ctrl+T 新建标签，按 Ctrl+L 输入另一个目录回车；Ctrl+Tab／Ctrl+Shift+Tab、Ctrl+PageDown／PageUp、Ctrl+1…9 在标签间切换；Ctrl+W 或 Ctrl+F4 关闭标签（最后一个标签按下时不应关闭）；换到右面板重复；Alt+←／→ 后退前进。
  - 预期：每个按键都只作用于蓝线所在的活动面板；键盘切面板后蓝线与焦点同时移动；另一个面板的标签、路径、选择不受影响；关闭最后一个标签时状态栏给出提示而不是关闭窗口。
  - 用户反馈：

- [ ] **鼠标：标签与活动面板**
  - 操作：点击标签切换；点标签上的 × 关闭；鼠标中键点标签关闭；点末尾“+”新建；点另一面板的空白处、文件项、路径栏；开 20 个以上标签后用滚轮横向滚动标签带。
  - 预期：点哪个面板，哪个面板的顶边出现蓝线并成为键盘作用目标；中键关闭与 × 一致；标签多时缩到最小宽度并可滚动，当前标签自动滚入视野；标签带的悬停、按下反馈自然。
  - 用户反馈：

- [ ] **双栏／单栏切换（Ctrl+\ 或工具栏“双栏”）**
  - 操作：在两个面板里各留 2 个标签、选中不同文件；点“双栏”切为单栏，再按 F6 在单栏下切到另一侧，再按 Ctrl+\ 切回双栏。
  - 预期：单栏只显示活动面板并占满内容区；隐藏的一侧回到双栏时标签、位置、选择、排序与视图原样；初始双栏时两个面板等宽。
  - 用户反馈：

- [ ] **重启恢复（真实使用）**
  - 操作：双栏各开几个标签，设置不同的排序与视图（例如一个标签按大小降序的列表，另一个按名称的网格），切到单栏，关闭程序再打开。
  - 预期：两侧标签、位置、各标签的排序与视图、活动面板、单栏状态都恢复；隐藏侧标签仍在；窗口立即出现，不因标签多而卡顿；没有自动打开任何文件。
  - 用户反馈：

- [ ] **真实磁盘拔出或目录被删除后的恢复**
  - 操作：在 U 盘或可移动磁盘上打开目录并放在某个标签里，关闭程序，拔出 U 盘后重新打开；或关闭程序后删除某标签对应的目录再打开。再插回 U 盘或恢复目录，切到该标签，点“重试”或按 F5。
  - 预期：程序正常启动，标签仍在并带“位置不可用”提示与可读原因，没有崩溃、没有反复重试；位置恢复后手动重试即可正常显示。
  - 用户反馈：

- [ ] **会话损坏时的提示**
  - 操作：关闭程序，用记事本把 `%LOCALAPPDATA%\slint-file-manager\session.json` 改成无法解析的内容（例如删掉末尾括号），再启动。
  - 预期：程序以默认双栏启动，状态栏说明原会话已备份；同目录出现 `session.backup-…-corrupt.json`，内容与损坏前一致；不假装恢复成功。
  - 用户反馈：

## Issue #7：磁盘、收藏与目录变化同步（需真实设备）

- [ ] **真实 U 盘插入与拔出**
  - 操作：程序运行中插入 U 盘；约 2 秒内观察侧栏“此电脑”；进入 U 盘目录后直接拔出（先确认没有复制任务）。
  - 预期：插入后侧栏出现带 U 盘图标的盘符与卷标；拔出后侧栏条目消失，正在浏览它的标签显示“位置不可用”，程序不崩溃；再次插入后点“重试”或 F5 恢复浏览。
  - 用户反馈：

- [ ] **浏览 U 盘时“安全删除硬件”**
  - 操作：在某标签中浏览 U 盘（可在里面外部新建文件），然后用系统托盘“安全删除硬件”弹出。
  - 预期：不提示“设备正在使用”（可弹出磁盘只做轻量轮询，不持有目录句柄）；在其他程序里新建／删除文件后约 1.5～3 秒内列表更新。
  - 用户反馈：

- [ ] **外置硬盘（USB 硬盘）与手机／相机**
  - 操作：接入 USB 移动硬盘、再接入手机（MTP）或相机。
  - 预期：移动硬盘作为磁盘出现并可浏览；手机、相机不出现在侧栏（本期不支持非磁盘设备）。
  - 用户反馈：

- [ ] **收藏在盘符变化后的表现**
  - 操作：收藏 U 盘上的目录，拔出后重启程序；再插入另一个 U 盘并使其占用同一盘符；最后插回原 U 盘。
  - 预期：拔出时该收藏灰显并带警告标记；换成另一个 U 盘后仍标为失效，不会悄悄指向新盘上的同名路径；插回原 U 盘后恢复为可用。
  - 用户反馈：

- [ ] **OneDrive／iCloud 入口**
  - 操作：在装有 OneDrive 或 iCloud 云盘的机器上启动程序。
  - 预期：侧栏“云盘”分组出现对应入口，点击进入本地同步目录；浏览时不会触发云端文件下载；未安装则不显示该分组。
  - 用户反馈：

- [ ] **外部修改的真实感受**
  - 操作：浏览一个目录，在资源管理器中批量复制 200 个文件进来、重命名、删除其中一些。
  - 预期：列表随之更新、不闪烁；已选中的文件保持选中；界面不卡顿，没有重复条目；F5 可手动刷新。
  - 用户反馈：
