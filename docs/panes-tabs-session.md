# 双栏、独立标签与会话恢复

依据 Issue #6 与 [ADR 0002](adr/0002-independent-tabs-per-pane.md)。术语见 [GLOSSARY.md](../GLOSSARY.md)：浏览面板、浏览标签、双栏、浏览会话。

## 状态模型（`src/browse/`）

- `Workspace`（`workspace.rs`）持有两个 `Pane`（0 左、1 右）、活动面板、是否双栏。**不存在全局标签**：标签只属于某一个面板。
- `Pane` 持有 1–100 个 `Tab`（`MAX_TABS = 100`）和当前标签序号；面板至少保留一个标签。
- `Tab`（`tab.rs`）持有自己的位置、前进后退历史、排序、视图方式、选择、光标与读取状态。排序与视图按**标签**独立，不是按面板。
- 读取结果带 `TabId` 回到界面线程，按标签应用：标签已关闭则丢弃；标签在后台（非当前标签、隐藏面板）时照常写入该标签，不影响界面；同一标签的过期结果（连续导航）被丢弃。
- **惰性读取**：标签从会话恢复后是 `Idle`，只有成为“可见面板的当前标签”时才读取。标签再多也不阻塞窗口显示。
- **位置不可用**：读取失败（目录被删、磁盘未连接、无权限、指向文件）时标签保留并标记不可用（标签上有警告图标，内容区显示原因与“重试”）。每次激活该标签只重试一次，不自动循环；点“重试”或 F5 手动重试。
- **单栏只是隐藏**：另一侧面板的全部状态（标签、选择、历史、排序、视图）留在内存并随会话保存；再切回双栏时原样出现。单栏显示的是活动面板，F6 同时切换显示的一侧。

## 活动面板

- 活动面板 = 键盘焦点所在的面板。对某个面板的任何操作（点击条目／标签／路径栏／空白、点击标签带按钮、在其地址栏输入）都会先把它设为活动面板并把焦点交给它，所以鼠标和键盘看到的是同一个活动面板。
- 活动面板的标识：面板顶边 2px 蓝线、当前标签为白底（非活动面板的当前标签为灰底）；元素树里面板 `groupbox` 的描述为“活动面板”；窗口属性 `active-pane`／`focused-pane` 可读。
- 工具栏（排序、视图）、侧栏“主目录”、状态栏与全部快捷键都只作用于活动面板。

## 快捷键（作用于活动面板）

沿用 Windows 与浏览器习惯：

| 操作 | 按键 |
| --- | --- |
| 新建标签（复制当前位置、排序、视图，不带历史与选择） | Ctrl+T |
| 关闭当前标签（最后一个不关闭，状态栏提示） | Ctrl+W 或 Ctrl+F4；也可点标签上的 ×、鼠标中键点标签 |
| 下一个／上一个标签（首尾相接） | Ctrl+Tab／Ctrl+Shift+Tab，或 Ctrl+PageDown／Ctrl+PageUp |
| 切到第 1–8 个标签／最后一个标签 | Ctrl+1…8／Ctrl+9 |
| 切换活动面板（单栏时同时切换显示的一侧） | F6 |
| 双栏／单栏切换 | Ctrl+\ 或工具栏“双栏”按钮 |
| 后退／前进／上一级／刷新 | Alt+←／Alt+→／Alt+↑（Backspace 也后退）／F5 |
| 编辑地址 | F4、Ctrl+L、Alt+D |

Ctrl+PageUp／PageDown 留给切换标签，因此内容区的整页滚动只响应不带 Ctrl 的 PageUp／PageDown。

## 外部请求打开目录

命令行 `--open=<目录>`：没有可恢复的会话时作为左面板起点；有会话时按 ADR 0002 处理——优先激活已打开该路径的标签（先左后右，单栏时显示那一侧），否则在当前面板新开标签。不打开任何文件内容。

## 会话文件

位置：`%LOCALAPPDATA%\slint-file-manager\session.json`。可用环境变量 `SFM_DATA_DIR` 或启动参数 `--data-dir=<目录>` 覆盖（测试一律用临时目录）；`--no-session` 不恢复也不保存。`--smoke`、`--bench-enter` 默认不读写会话，除非显式给出 `--data-dir=`。

格式（UTF-8 JSON，顶层必有整数 `version`，当前为 1）：

```json
{
  "version": 1,
  "saved_at": "2026-11-08T12:00:00+08:00",
  "split": true,
  "active_pane": 0,
  "panes": [
    {
      "active": 1,
      "tabs": [
        {
          "location": "C:\\Users\\me\\图片",
          "sort": { "key": "name", "ascending": true },
          "view": "grid",
          "back": ["C:\\Users\\me"],
          "forward": []
        }
      ]
    },
    { "active": 0, "tabs": [ ... ] }
  ]
}
```

- `sort.key`：`name`／`modified`／`size`／`kind`；`view`：`grid`／`list`。每个面板至少 1 个标签，最多 100 个；`active` 越界时收敛到最后一个标签；历史各最多保留 50 条。
- 不保存：选择、光标、滚动位置、文件内容；恢复不会自动打开任何文件。
- 保存时机：状态变化后至多约 2 秒写盘一次，正常退出时再写一次。写入用“临时文件 + 重命名”，写到一半崩溃不会留下半个文件。
- **降级规则**：文件无法解析、结构不符、过大（> 4 MiB）、版本不是当前版本时，**不使用也不覆盖**原文件，而是把它移动成 `session.backup-<yyyyMMdd-HHmmss>-<corrupt|v版本号>.json`（保留最近 5 个），本次使用默认会话，并在状态栏显示说明（不会假装恢复成功）。备份失败时本次运行不再写会话，原文件保持不动。
- 默认会话：双栏、两侧各一个标签，左为启动目录（或主目录）、右为主目录。

## 验证入口

- 单元测试：`cargo test --lib`（`browse::workspace`、`browse::session`、`browse::tab`、`browse::history`）。

- 真实程序重启闭环：`powershell -File scripts/verify-session.ps1`（release exe + 临时数据目录，已包含在 `scripts/verify.ps1`）。
